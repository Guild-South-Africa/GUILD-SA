04 / Guild Sprint / Hackathon / Demo Day

Every minute is accounted for.

A Guild event is a disciplined production environment: setup, check-in, planning, build blocks, checkpoints, demos, judging, awards, capture, and follow-up.

01

Event day structure

The schedule protects the build.

The format is built for urgency. Brief moments are brief. Build blocks are protected. Demos happen whether teams feel ready or not.

07:30

Setup

Venue dress, table layout, equipment check, name badges, QR codes, lanyards, and sticker packs.

08:30

Opening ceremony

GUILD SA story, rules explained, judging criteria shared, and "No MVP = No Judgement" declared.

09:00

Planning phase

Teams define the problem statement, MVP scope, required stack, and team responsibilities.

10:00

Build block 1

Heads down. Mentors on standby. No interruptions unless a team is blocked.

12:00

Checkpoint 1

Each team shares a 60-second progress update. Mentors identify scope risk early.

13:00

Build block 2

Final push toward a shippable MVP. GitHub commits required. No vague progress.

16:30

Submission deadline

GitHub or deployed link submitted. No late submissions accepted.

17:00

Demo session

Each team gets a 3-5 minute pitch plus judge Q&A. Audience votes via QR.

19:30

Results & awards

Top three announced. Guild Labs pathway explained. Photos, networking, and survey follow.

100

Judging system

Teams are judged on output, impact, fit, and edge.

The scorecard rewards working product, South African relevance, problem-solution clarity, and meaningful innovation or AI usage.

25%

MVP execution

Does it work? Can the team demo it live, right now?

30%

Impact potential

Could this scale? Does South Africa need this?

25%

Problem fit

Is this a real problem, and does the MVP actually solve it?

20%

Innovation

Is there a creative or technical edge? Is AI used meaningfully?

72h

Post-event is critical

The sprint is not over when awards end.

Project evidence is captured while the signal is still hot. Screenshots, demos, team photos, GitHub links, participant quotes, and sponsor-ready recaps are published within 72 hours.

Capture

Document every project

Screenshots, GitHub links, team photos, demo footage, and quotes.

Publish

Showcase fast

Project showcase, recap reel, winners, and partner-ready proof.

Follow-up

Move teams forward

Survey, results email, Labs invitations, and mentor pathway.
